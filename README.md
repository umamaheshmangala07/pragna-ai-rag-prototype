# pragna-ai-rag-prototype

Retrieval-Augmented Generation (RAG) prototype for PragnaAI — built with
LangChain, HuggingFace, and Chroma for querying agricultural and startup
guidance content, with Telugu-language support.

## What changed from the first version

1. **Multilingual embeddings** — swapped the English-only
   `all-MiniLM-L6-v2` for `paraphrase-multilingual-MiniLM-L12-v2`, which
   actually understands Telugu (and 50+ other languages).
2. **Real answer generation** — added an `ask()` function that retrieves
   relevant chunks *and* sends them to Azure OpenAI to generate an actual
   answer, not just raw text fragments. Works without Azure credentials
   too (falls back to showing retrieved context).
3. **Works without a PDF** — `initialize_rag_pipeline()` now accepts
   either a `pdf_path` or a plain Python list of text passages
   (`texts=[...]`), so you can test immediately.
4. **Persisted vector store** — embeddings are saved to disk
   (`./pragna_vectorstore`) instead of being rebuilt every run.
5. **A test that actually tests something** — `test_retrieval()` builds a
   small sample agricultural knowledge base (English + Telugu) and asks a
   real Telugu farming question against it.
6. **Fixed a dependency mismatch** — `PyPDFLoader` needs the `pypdf`
   package, not `PyPDF2` (which was in the original requirements.txt).

## Setup

```bash
pip install -r requirements.txt
```

Optional — for real generated answers instead of raw retrieved context,
copy `.env.example` to `.env` and fill in your Azure OpenAI details from
[ai.azure.com](https://ai.azure.com), then load them before running
(e.g. with `python-dotenv`, or export them in your shell).

## Run the demo

```bash
python rag_pipeline.py
```

This builds a tiny in-memory knowledge base with one English and two
Telugu passages about crop sowing, asks "వేరుశనగ ఎప్పుడు విత్తాలి?"
("When should groundnut be sown?"), and prints the answer — either
generated by Azure OpenAI (if configured) or the raw relevant passage
(if not).

## Using your own content

Swap the sample passages for real data:

```python
from rag_pipeline import initialize_rag_pipeline, ask

# From a PDF (e.g. state agribusiness/subsidy guidelines)
retriever = initialize_rag_pipeline(pdf_path="AP_startup_subsidy_guidelines.pdf")

# Or from plain text you've collected
retriever = initialize_rag_pipeline(texts=["your passage 1", "your passage 2"])

answer = ask(retriever, "your question here")
print(answer)
```

## Known limitations (things to improve next)

- No chunk-size tuning yet — `PyPDFLoader.load_and_split()` uses default
  splitting, which may cut passages awkwardly for long documents.
- No source citation in the generated answer (which passage it came
  from) — worth adding once you're testing with real documents.
- Retrieval quality on Telugu hasn't been tested against a large,
  real-world document yet — the demo uses only 3 short passages.
- No evaluation harness — before trusting this for real farmer-facing
  answers, you'll want a test set of question/expected-answer pairs to
  check accuracy, especially given health and agriculture advice carries
  real consequences if wrong.
